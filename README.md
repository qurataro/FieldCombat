## ファミコン版とアーケード版の違い

ファミコン版をプレイした後に、アーケード版をプレイしました。その結果、体感としてファミコン版にはないスピーディーで迫力のある展開に衝撃を受けました。

以下にファミコン版とアーケード版の比較を記載しました。

|                    | ファミコン版         | アーケード版                       |
| ------------------ | -------------------- | ---------------------------------- |
| 敵の攻撃           | 序盤緩め、後半激しめ | 序盤から激しめ                     |
| 敵陣ゲート前の砲台 | あり                 | なし                               |
| ゲートくぐった後   | 特になし             | フィールドで戦ってる敵が味方になる |

## 改変の内容

### 敵陣ゲート前の砲台を取っ払う

アーケード版には敵陣ゲート前の砲台がないので、取っ払いました。

これはアーケード版に似せるという意図以外に、敵の攻撃を避けながら敵陣のゲートに滑り込むことで戦闘を一瞬で停止させるというこの緊張感とスピーディーさが、砲台によって失われてしまうからです。

### ゲートをくぐった後、フィールドで戦っている敵が味方になる

ファミコン版は、占領した後は生存している味方の兵力は維持されますが、吸い込んだ敵以外の占領時に戦っている敵は味方になりません。しかし、アーケード版は敵陣のゲートをくぐった瞬間にフィールドで戦っていた敵がすべて味方になります。回転しながら自分の陣地に吸い込まれるあの爽快感を再現するため、回転しながら自分の陣地に吸い込まれる演出も入れました。

### 敵の攻撃を序盤から激しくする

ファミコン版は、序盤は攻撃を少なめにし、後半で入口の大砲の撃破でもたついている間に敵が攻撃を仕掛けてゆく手を阻む演出がありました。しかし砲台を取っ払うことで、猛攻撃が始まる前にゲートに滑り込めてしまうので、ゲームの難易度がかなり下がってしまいました。

そのため、序盤から攻撃を激しくすることでアーケード版に近い形になりました。
